# HANAX-U

HANAX-Uは、COEIROINK（`.cink`）やVOICEVOX（`.vvproj`）で作った読み上げ音声のプロジェクトを読み込み、OpenUtauで開けるファイル（`.ustx`）を出力するブラウザアプリケーションです。UTAU音源を使った読み上げ風音声、いわゆる「HANASU」を作るときの下書きとして使うことを想定しています。

モーラとアクセント情報を取得し、藤崎モデル（F0生成モデル）を参考にしたアルゴリズムで音高を再計算します。そのため、元プロジェクトの音高を完全に再現するものではありません。

HANAX-Uは、複雑なピッチ曲線や細かな調声を最初から生成するのではなく、半音単位のノート音高を中心とした、編集しやすいUSTXを出力します。音源に合わせた調声、細かな音高変化、タイミングなどを、出力後にOpenUtauで自由に仕上げることができます。

## 現在の提供方針

HANAX-Uはv0.xの試験段階にあります。COEIROINK・VOICEVOXのプロジェクトから、OpenUtauで編集しやすいUSTXの下書きを出力する中心機能は利用できます。

HANAX-Uは個人によるバイブコーディングで制作しており、確認できる環境やテストには限界があります。異なるブラウザ、OpenUtau、UTAU音源、動画制作環境での動作報告をGitHub Issuesで歓迎します。すべての報告への個別対応や修正を約束するものではありませんが、今後の確認・改善の参考にします。

TXT・LABを使う動画制作ツールとの連携は、今後の改善目標です。各ツールとの個別の連携確認は、まだ十分に行えていません。動画制作へ進む場合は、[制作者向けワークフロー](docs/for-creator.md)を参照してください。

複数話者の会話制作に向け、話者ごとの音高・UTAUフラグ設定も今後の改善候補です。音高は生成処理を含む設計の見直しが必要であり、トラックごとのUTAUフラグ設定はOpenUtau安定版の対応を待っているため、現時点では提供していません。

## 利用ガイド

### [はじめての一言を作る](docs/first-steps.md)

UTAUやHANASUを初めて使う方を想定したガイドです。好きなUTAU音源に、5〜10秒程度の短いオリジナル台詞を言ってもらうところまでを案内しています。

### [制作者向けワークフロー](docs/for-creator.md)

UTAUに慣れていて、動画制作の経験がある方を想定したガイドです。OpenUtauでの仕上げと、動画制作環境への受け渡しを案内しています。

## 基本の使い方

1. [GitHub Pagesの公開ページ](https://p-cyclase.github.io/HANAX-U/)を開きます。ローカルで使いたい場合は、[Releaseページ](https://github.com/p-cyclase/HANAX-U/releases)から最新版のZIPをダウンロードし、解凍したフォルダ内の`index.html`を開きます。
2. 必要に応じて「基本設定」「詳細設定」を入力します。分からなければ、変更しなくても大丈夫です。
3. `.cink`または`.vvproj`ファイルをドラッグ＆ドロップします。もしくはクリックして、ファイルを選択します。
4. 読み込み後に基本設定・詳細設定を変更した場合は、「設定を反映」を押します。
5. 必要に応じて「出力設定」を入力します。分からなければ、変更しなくても大丈夫です。
6. 「.ustx をダウンロード」または「セリフ付きZIPをダウンロード」を選択します。
7. ダウンロードした`.ustx`ファイルをOpenUtauで開き、必要に応じて編集・音声出力を行ってください。ZIPを選んだ場合は、展開したZIP内の`.ustx`ファイルを開きます。

## 出力を選ぶ

| 出力 | 向いている用途 |
| --- | --- |
| `.ustx をダウンロード` | OpenUtauで音源・歌詞・音高・タイミングを編集して仕上げる。 |
| `セリフ付きZIPをダウンロード` | USTXに加え、動画制作で使うセリフTXTと、必要に応じた口パク用LABを用意する。 |

セリフ付きZIPの中身、OpenUtauでのWav出力、動画制作ツールへ渡す際の注意は、[セリフ付きZIP・動画連携ガイド](docs/zip-and-video-workflow.md)を参照してください。

## USTX整頓モード（試験機能）

通常変換とは別に、OpenUtauで作成・編集したUSTXから、動画制作向けのトラック名、TXT、必要に応じてLABを整え直す上級者向け機能です。通常の変換フローを分かりやすく保つため、画面上の対応形式には表示していませんが、`.ustx`ファイルをドロップまたは選択すると使えます。

LABの特殊音素対応には制約があります。詳しい使い方と既知の制約は、[制作者向けワークフロー](docs/for-creator.md#ustx整頓モード試験機能)を参照してください。

## 対応形式と注意事項

| 種別 | 内容 |
| --- | --- |
| 入力 | COEIROINK `.cink`、VOICEVOX `.vvproj`（試験機能として編集済みUSTX `.ustx`にも対応） |
| 出力 | OpenUtauプロジェクト `.ustx` |
| セリフ付きZIP | `.ustx`、トラックごとのセリフTXT、必要に応じて同名の口パク用LAB、変換ログ |

- プロジェクトデータの読み込み・変換・出力は、すべてブラウザ内で行います。入力したプロジェクトの内容をHANAX-Uのサーバーへ送信することはありません。
- 変換前の元プロジェクトは、必ず残しておいてください。うまくいかなかった場合も、元ファイルがあれば変換をやり直せます。
- 入力ファイルは20 MBまでです。圧縮されたCOEIROINKプロジェクトは、展開後の合計サイズを50 MBまでに制限しています。
- 出力されたUSTXが、すべてのOpenUtauのバージョン・UTAU音源・rendererで正しく動作することや、期待した音声品質になることは保証できません。
- 対応範囲外のプロジェクト構造や、将来変更されたCOEIROINK・VOICEVOXの仕様は正しく読み込めない場合があります。

## Q&A

### 元のCOEIROINK／VOICEVOXと同じ声・同じ音程になりますか？

なりません。HANAX-Uは、元プロジェクトのアクセント情報を参考にして、UTAU音源で使うための新しい音程を作ります。元プロジェクトの実測ピッチ、モーラごとの長さ、子音長、母音長は再現しません。

### VOICEVOXを読み込んだら、話者名が変な文字列になります

VOICEVOXのプロジェクトファイルには、キャラクター名やスタイル名そのものではなく、話者を識別するための内部IDが保存されています。HANAX-Uでは、このIDをそのまま表示します。

変な文字列に見えてもエラーではありません。変換結果プレビューの台詞を見て、どの話者IDがどのキャラクターに対応するかを確認してから、話者マッピングを設定してください。

### singerなどの設定が分かりません

空欄のままUSTXを出力して問題ありません。OpenUtauで音源を設定してから編集できます。話者ごとに音源を使い分けたい場合だけ、`Singers`フォルダ内の音源フォルダ名を入力してください。

### 「セリフ付きZIP」は何に使いますか？

`.ustx`に加えて、トラックごとのセリフTXTと、必要に応じて口パク用LABをまとめて出力します。OpenUtauでWavファイルを出力したあと、動画制作ツールでセリフと音声ファイルを対応付ける用途を想定しています。詳しくは、[セリフ付きZIP・動画連携ガイド](docs/zip-and-video-workflow.md)を参照してください。

### うまく読み込めません

通常の変換で対応している入力形式は`.cink`と`.vvproj`です。ファイルが壊れていないか、元のソフトウェアで開けるかを確認してください。画面に表示されたエラーメッセージも、不具合報告の際に役立ちます。

### オフラインでも使えますか？

ZIPとYAMLの処理に必要なライブラリは同梱しているため、ローカルに保存したHANAX-Uを開く場合でも、変換とダウンロードの機能は利用できます。ただし、文字の見た目に使っているInterフォントはインターネットから読み込むため、オフライン時は別のフォントで表示され、見た目が少し変わることがあります。
