# テストデータ

このフォルダには、HANAX-Uの実装・動作確認に使う決定稿のテストデータを置く。`sample/`は利用者がローカルで参照する実用サンプル用であり、Git管理するテストデータとは分ける。

テストデータには、絶対パス、Windowsユーザー名、メールアドレスなど、利用者の環境や個人を特定し得る情報を含めない。台詞本文には、公開リポジトリで扱える権利関係が明確なテキスト、またはオリジナル文を使う。

ファイル名で対象機能と目的を区別する。現時点ではUSTX再同期モード用のデータを置いているが、将来はCOEIROINK・VOICEVOXの入力、通常のUSTX出力、ZIP、LAB、エラー表示など、他機能のテストデータもこのフォルダへ追加する。

通常変換用テストプロジェクトの要件と追加手順は、[通常変換テストデータ仕様](../docs/normal-conversion-test-fixtures.md)を参照する。

## 通常変換

### `normal_success.cink` / `normal_success.vvproj`

COEIROINK・VOICEVOXの通常変換に共通して使う正常系サンプル。太宰治『斜陽』の一節を台詞として使用する。

- 3件のセリフ、読点による休止、促音、撥音`ん`、末尾の疑問文を含む。
- COEIROINK版は、架空の話者IDに対する2スタイル（`styleId: 0 / 1`）を含む。表示名`蛸之風みもり`は管理者が公開を許可した名称を使用する。
- VOICEVOX版は、架空の話者IDに対する2スタイル（`styleId: 0 / 1`）と、VOICEVOX内部のカタカナモーラを含む。
- 話者・エンジンのUUIDは架空値へ置換済みであり、特定の実在音源・エンジンを指定しない。

期待結果は、両ファイルでプレビュー、USTX単体、TXT ZIP、LAB有効時のZIPを正常に出力できること。COEIROINK・VOICEVOXの話者マッピング候補がそれぞれ2種類に分かれ、VOICEVOXのモーラがひらがなとしてUSTXへ出力されることも確認する。

### `normal_invalid.cink` / `normal_invalid.vvproj`

拡張子は正しいがJSONとして不正な入力を確認する最小サンプル。内容は`{`の1文字だけである。

期待結果は、変換を開始せず、プロジェクトファイルを読み取れないことを示す画面内エラーを表示すること。

### `normal_invalid_zip.cink`

先頭の`PK`だけを含む壊れたZIP入力を確認するための2バイトファイル。

期待結果は、変換を開始せず、壊れた圧縮ファイルであることを示す画面内エラーを表示すること。

### `normal_empty.cink`

空ファイルの入力を確認するための0バイトファイル。

期待結果は、変換を開始せず、ファイルが空であることを示す画面内エラーを表示すること。

## USTX再同期モード

### `resync_success.ustx`

再同期モードの正常系を確認するための総合サンプル。

- USTXのファイル名と内部`name`が異なる。
- 3トラック、singerあり・なし、任意の元トラック名を含む。
- 同一トラックに複数アイテムがあり、アイテム名を連結したTXTを確認できる。
- ノート間、アイテム間、トラック先頭の空白を含み、LABの`sil`補完を確認できる。
- `R`、`ん`、通常のかなを含む。
- 通常の発声モーラに続く`+`を含み、母音継承を確認できる。
- BPM 240から200へのテンポ変更を含む。

期待結果は、再同期ZIPが正常に出力されること。再命名済みUSTX、TXT、LAB有効時のLAB、ログを確認する。入力USTXと出力USTXをYAMLとして比較し、各トラックの`track_name`以外の全フィールドが一致することも確認する。

### `resync_warning.ustx`

再同期モードが出力を継続しつつ、LABの`sil`フォールバックとZIP内ログ警告を出すケースを確認するサンプル。

- 音源固有のsuffixとして一般的な`↑`を含む。
- 音源固有のsuffixとして一般的な`↓`を含む。
- 珍しいエイリアスを想定した`w`付き歌詞を含む。
- 先頭の`+`を含み、引き継ぐ母音がない場合の警告を確認できる。
- 空欄歌詞を含む。
- VCなどの特殊音素を想定した`i t`、`o n`、`a s`などを含む。

期待結果は、再同期ZIPが出力され、該当LABラベルが`sil`となり、ZIP内ログに警告が記録されること。正常な`+`の確認は`resync_success.ustx`で行う。警告があっても、各トラックの`track_name`以外のUSTXデータは入力から変わらないことを確認する。

### `resync_error1.ustx`

同一アイテム内でノート区間が重なるケース。

期待結果は、再同期ZIPを出力せず、同一トラック内の重なりを解消するよう画面内エラーを表示すること。

### `resync_error2.ustx`

複数アイテム間でノート区間が重なるケース。

期待結果は、再同期ZIPを出力せず、同一トラック内の重なりを解消するよう画面内エラーを表示すること。

### `resync_error3.ustx`

テンポ一覧にBPM 0を含むケース。

期待結果は、再同期ZIPを出力せず、不正なテンポ情報があることを画面内エラーで表示すること。ノートがそのテンポ変更位置まで到達しない場合でも、テンポ一覧全体を検証して中止する。
