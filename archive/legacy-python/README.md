# 旧Python実装

このフォルダには、HANAX-Uの初期試作として作成されたPython版の変換処理と、その旧テストを保管しています。

## 現在の扱い

- 現行のHANAX-Uは、ブラウザで動作する`converter.js`と`app.js`を使用します。
- このフォルダ内のPythonコードは、現行のUI・USTX出力・音高生成・LAB出力の仕様に追従していません。
- 通常の利用、公開前テスト、機能追加の実装対象には含めません。
- 過去の設計や実装経緯を参照する必要がある場合だけ確認してください。

## 保管ファイル

- `cink2ustx.py`: 初期のPython変換処理
- `test_converter.py`: 上記実装用の旧テスト
