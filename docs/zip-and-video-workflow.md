# セリフ付きZIP・動画連携ガイド

このガイドでは、HANAX-Uの「セリフ付きZIP」を使い、OpenUtauから書き出すWavとセリフTXT・口パク用LABを対応させるまでを説明します。動画制作ツール側で必要になる設定やプラグインは利用環境ごとに異なります。確認済み・未検証の範囲は、[動画制作ツールとの連携状況](video-integration-status.md)を参照してください。

## セリフ付きZIPに入るもの

セリフ付きZIPには、次の構成でファイルが入ります。

```text
プロジェクト名.zip
├─ プロジェクト名.ustx
├─ Export/
│  ├─ プロジェクト名_トラック名.txt
│  └─ プロジェクト名_トラック名.lab  （「.labも出力する」をオンにした場合）
└─ Log/
   └─ 変換ログ
```

- `.ustx`：OpenUtauで開いて編集するプロジェクトファイルです。
- `.txt`：各トラックのセリフです。
- `.lab`：口パクに使う、モーラと休符の時間範囲・母音ラベルを記録したファイルです。必要な場合だけ出力します。
- `Log`：変換時の設定と処理結果を記録します。内容が分からない場合は、削除してもUSTX・TXT・LABの利用には影響しません。

## WavとTXT・LABを対応させる手順

1. HANAX-Uでプロジェクトを読み込み、「セリフ付きZIPをダウンロード」を選びます。口パク用LABも必要な場合は、出力設定で「`.labも出力する`」をオンにします。
2. ダウンロードしたZIPを展開します。
3. ZIP内の`.ustx`をOpenUtauで開き、必要に応じて音源、歌詞、音高、タイミングを編集します。
4. OpenUtauのメニューから「ファイル」→「音声をエクスポート」→「Wavファイルを出力」を選びます。
5. `Export`フォルダ内に、トラックごとのWavファイルが出力されます。TXT・LABとWavは、拡張子以外のファイル名が同じになります。

この対応を保つため、Wavを書き出す前にUSTXのプロジェクト名・トラック名・BPMを変更しないことをおすすめします。

## 編集後に気を付けること

OpenUtauでノート位置や長さを変更すると、通常モードで出力済みのLABとは時間が合わなくなります。編集後のLABを作り直したい場合は、次のどちらかを利用してください。

- 編集済みUSTXをHANAX-Uへ読み込み、[USTX整頓モード](ustx-organization-mode-specification.md)でTXT・必要に応じてLABを再出力する。
- OpenUtauで利用できるLAB出力プラグインなどを使い、LABを再出力する。

USTX整頓モードは試験機能です。suffix・エイリアス・VC・CVVCなどの特殊音素では、LABの母音判定が期待どおりにならない場合があります。LABを使う場合は、ZIP内のログと実際の口パク結果を確認してください。

## ファイル名形式

出力設定の「セリフ付きZIP設定」では、TXT・LAB・OpenUtauから出力するWavの対応に使うファイル名形式を選べます。

- 連番のみ：`プロジェクト名_001`
- 連番_セリフ：`プロジェクト名_001_セリフ`
- 連番_singer_セリフ：`プロジェクト名_001_singer_セリフ`

singerを含める形式で、singer欄に相対パスを入力した場合は、末尾の音源フォルダ名だけを使います。詳細は[制作者向けワークフロー](for-creator.md)を参照してください。

## 動画制作ツールで使う前に

HANAX-Uは、同名のWav・TXT・LABを用意するところまでを担当します。動画制作ツールでの自動配置、キャラクターID、口パク、字幕の結果は、ツール・プラグイン・バージョン・個別設定に依存します。

最初は短いセリフ1つだけで、Wav・TXT・LABが意図どおりに連携するかを確認してから、複数話者の制作へ広げることをおすすめします。

詳しい確認状況と、外部ツール側で決まる事項は[動画制作ツールとの連携状況](video-integration-status.md)を参照してください。
