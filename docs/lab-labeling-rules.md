# LABラベル判定規則

> **対象：通常モード・USTX整頓モード共通の内部仕様**
>
> この文書は、ノート歌詞からLABのラベルを決める規則だけを扱う。ZIPの構成、ファイル名、時刻計算、整頓モード固有の空白`sil`は、それぞれの仕様を参照する。

## 目的

LABのラベルは`a`、`i`、`u`、`e`、`o`、`N`、`sil`のいずれかとする。音源固有のsuffix・エイリアス・VCなどを音素辞書で解析せず、歌詞中のかなと前後のラベルの連続性を使って決定する。

## 判定順序

各トラックは、開始時点で`sil`を保持した状態から始める。各ノートを時間順に処理し、直前に確定したラベルを保持する。

1. 歌詞が休符`R`の場合は`sil`を出力し、保持するラベルを`sil`へ更新する。
2. それ以外の歌詞を末尾から1文字ずつ探索する。
   - 最初に見つかる`ん`・`ン`は`N`とする。
   - 最初に見つかる母音を持つかなは、対応する`a` / `i` / `u` / `e` / `o`とする。
3. かなが見つからない場合、保持しているラベルをそのまま継続する。トラック先頭や休符・空白の直後では、保持している`sil`を継続する。

ノート間の空白を`sil`として追加する場合も、保持するラベルを`sil`へ更新する。

## 例

| 歌詞 | 条件 | LABラベル |
| --- | --- | --- |
| `きゃ` | 末尾から`ゃ`を発見 | `a` |
| `ん↑` | 末尾から`ん`を発見 | `N` |
| `あw` | 末尾から`あ`を発見 | `a` |
| `a k` | かななし・直前ラベルが`a` | `a` |
| `+` | かななし・直前ラベルが`i` | `i` |
| `- s` | かななし・トラック先頭の保持ラベルが`sil` | `sil` |
| `R` | 休符 | `sil` |

## 制約

この規則は、suffix・エイリアス・特殊音素が本来どの口形を表すかを復元するものではない。かなを含まない表記では、直前のラベルを保つことを優先する。語頭子音など、トラック先頭でかなを含まない表記は`sil`となる。口形の正確さが重要な場合は、実際の口パク結果を確認する。
