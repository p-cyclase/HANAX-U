# ファイル命名規則

> **対象：実装仕様・参考資料**
>
> 通常の利用手順は[セリフ付きZIP・動画連携ガイド](zip-and-video-workflow.md)を参照する。この文書は、通常変換とUSTX整頓モードに共通するトラック名・TXT・LAB・Wavの命名規則を定める。

## 目的

HANAX-Uは、OpenUtauがWavを「プロジェクト名_トラック名.wav」として出力する仕様を利用する。出力USTXのプロジェクト名・トラック名と、Exportフォルダに置くTXT・LABのファイル名を同じ規則で決めることで、Wav・TXT・LABの対応を保つ。

通常変換とUSTX整頓モードは、共通の命名処理と下記の上限値を使用する。

| 項目 | 規則 |
| --- | --- |
| 連番 | 1から始まる3桁ゼロ埋め（001など） |
| singer名 | 8文字まで |
| セリフ | 24文字まで |

## ファイル名形式

利用者は、出力設定で次のいずれかを選択する。

| 選択肢 | トラック名の形式 |
| --- | --- |
| 連番のみ | 001 |
| 連番_singer | 001_singer |
| 連番_セリフ | 001_セリフ |
| 連番_singer_セリフ | 001_singer_セリフ |

出力USTXのトラック名を「トラック名」としたとき、TXT・LAB・OpenUtauから出力されるWavは、それぞれ「プロジェクト名_トラック名.txt」「プロジェクト名_トラック名.lab」「プロジェクト名_トラック名.wav」となる。

## プロジェクト名の決定

### 通常変換

入力した`.cink`または`.vvproj`のファイル名から拡張子を除いた文字列を、出力USTXのファイル名、USTX内部の`name`、TXT・LABの接頭辞に共通して使う。

たとえば`example.cink`を入力した場合は、`example.ustx`を出力し、USTX内部の`name`も`example`とする。OpenUtauでプロジェクト名・トラック名・BPMを変更せずにWavを書き出すと、TXT・LABと同じ接頭辞のWavを得られる。

### USTX整頓モード

整頓モードでは、入力した`.ustx`のファイル名から拡張子を除いた文字列を、整頓ZIP・再出力USTX・TXT・LABの接頭辞に使う。一方、入力USTX内部の`name`は変更しない。整頓モードはトラック名以外のUSTXデータを保持するためである。

## 文字列の整形

- ファイル名に使えない文字（< > : " / \\ | ? *、制御文字）は _ へ置き換える。
- 連続する空白文字は1つの半角空白へまとめる。
- 末尾の空白とピリオドは取り除く。
- 文字数上限は、整形後の文字列へ適用する。

### singer名

singer名に相対パスを含めた場合、ファイル名に使うのは、いちばん下層の音源フォルダ名だけである。USTXのsinger値そのものは、利用者が入力した相対パスを含む文字列を保持する。

通常変換では、話者マッピングで指定したsinger名を使う。singerが空欄の場合は、インポート元の話者識別文字列を代替として使う。USTX整頓モードでは、入力USTXトラックのsingerを使い、空欄の場合は singer を代替として使う。

### セリフ

通常変換では元プロジェクトから取得したセリフを、USTX整頓モードでは同一トラック内のアイテム名を位置順に連結した文字列を使う。どちらも、ファイル名に使う部分は24文字までに短縮する。

## 実装上の責務

共通の文字数上限、文字列整形、singer相対パスの扱い、トラック名の組み立ては filename-rules.js が担当する。通常変換のExporterとUSTX整頓モードは、この共通処理を呼び出し、モードごとの文字列の取得元だけを渡す。通常変換のUSTX内部`name`はExporterが入力ファイル名から受け取り、整頓モードでは入力USTXの値を維持する。

規則を変更する場合は、この文書、filename-rules.js、[公開前テスト計画](pre-release-test-plan.md)を同時に更新する。
