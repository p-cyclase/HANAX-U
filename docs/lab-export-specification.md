# 口パク用LAB出力仕様

> **対象：実装仕様・参考資料**
>
> セリフ付きZIPの使い方は[セリフ付きZIP・動画連携ガイド](zip-and-video-workflow.md)を参照する。この文書は、LAB出力の実装仕様を記録する。

## 状態と目的

この文書は、**通常モード**でセリフ付きZIPに動画制作ツールでの口パク利用を想定した`.lab`ファイルを追加するための実装仕様である。`.lab`はOpenUtauから書き出すWavと、既存のセリフTXTを対応付ける補助データであり、USTX単体ダウンロードには含めない。

HANAX-Uはv0.xの試験段階にあり、LABを含むファイル名対応は各種動画制作ツール・プラグインとの連携を目標とした実装である。外部ツール側での自動配置、キャラクターID、口パク結果はHANAX-Uの範囲外であり、すべての利用環境での動作確認は完了していない。確認済み・未検証の範囲は[動画制作ツールとの連携状況](video-integration-status.md)を参照する。

出力直後のUSTXをOpenUtauで開き、ノートの位置・長さを変更せずにWavを書き出した場合、Wav、TXT、LABは同じファイル名で対応する。USTXのファイル名・トラック名・BPM、またはノートの位置・長さを変更すると、通常モードで出力したTXT・LABとの名前または時間の対応は崩れる。

編集済みUSTXを基にTXT・LABを作り直す機能は、試験機能の[USTX整頓モード仕様](ustx-organization-mode-specification.md)で別途定義する。この文書は通常モードだけを対象とする。両モードに共通する母音判定は、[LABラベル判定規則](lab-labeling-rules.md)を参照する。

## セリフ付きZIP設定

出力設定の「セリフ付きZIP設定」には、ファイル名形式とLAB出力の有無を置く。どちらもExporterだけに影響し、変更してもImporterやGeneratorの再処理は行わない。次に「セリフ付きZIPをダウンロード」を押した時点で現在の設定を反映する。

### ファイル名形式

次のラジオボタンから、TXT・LAB・OpenUtauから出力するWavに共通するファイル名形式を選ぶ。初期状態は「連番のみ」だが、3つの形式に優劣や推奨はない。

| 選択肢 | 出力例 |
| --- | --- |
| `連番のみ` | `project-name_001` |
| `連番_セリフ` | `project-name_001_セリフ` |
| `連番_singer_セリフ` | `project-name_001_singer_セリフ` |

文字数上限、相対パスのsinger名、使用できない文字の扱いは、[ファイル命名規則](file-naming-rules.md)に従う。

### LAB出力

「`.labも出力する`」チェックボックスは初期状態でオフとする。オフの場合、ZIPの`Export/`にはトラックごとのTXTだけを出力する。チェックした場合は、各TXTと同名のLABも追加する。LABはPSDToolkitなどの動画制作ツールでの口パク利用を想定する。

## ZIP内の配置とファイル名

「`.labも出力する`」をチェックした場合、トラックごとにTXTとLABを同じ拡張子以外は完全に同一の名前で`Export/`へ出力する。

```text
project-name.zip
├─ project-name.ustx
├─ Export/
│  ├─ project-name_001.txt
│  ├─ project-name_001.lab
│  ├─ project-name_002.txt
│  └─ project-name_002.lab
└─ Log/
   └─ project-name_conversion.log
```

`001`などのトラック名は、利用者が選択したファイル名形式に従う。したがって`プロジェクト名_トラック名.txt`、`プロジェクト名_トラック名.lab`、OpenUtauが出力する`プロジェクト名_トラック名.wav`は同じ名前の組になる。チェックボックスがオフの場合はLABを生成しないが、TXTとWavの対応は従来どおり維持する。

## LABのテキスト形式

LABはUTF-8のプレーンテキストとし、各行を以下の3列、半角スペース区切りで出力する。最終行の末尾には改行を付ける。

```text
開始時刻 終了時刻 ラベル
```

- 時刻は10進整数で記述する。開始時刻が0の場合は、目標ファイルに合わせて`00000`と表記してよい。
- ラベルは`a`、`i`、`u`、`e`、`o`、`N`、`sil`のいずれかとする。
- 通常モードでは、USTXの各ノートに対してLABを1行出力する。発声モーラだけでなく、先頭・句境界・促音・末尾を含むすべての休符Rも行として出力する。USTX整頓モードでは、ノート間の空白を`sil`として追加するため、行数がノート数と一致しない場合がある。

## 時刻の算出

LABの時刻単位は、目標ファイルの実測値に合わせて**100ナノ秒単位**（1秒 = 10,000,000）とする。ナノ秒単位と呼ばれることがあるが、1秒 = 1,000,000,000の1ナノ秒単位ではない。

USTXの480 ticksを4分音符とし、各ノートの開始・終了tickをBPMから変換する。

```text
labTime(tick) = round(tick × 60 × 10,000,000 ÷ (480 × BPM))
```

各行の開始時刻にはノート開始tick、終了時刻には開始tick + 長さを与える。丸めは各絶対tick位置に対して行い、前行の終了時刻と次行の開始時刻が必ず一致するようにする。

HANAX-Uの現行ノート長はすべて240 ticksのため、1行の標準長は以下となる。

```text
300,000,000 ÷ BPM
```

BPM 200では1行 = `1500000`となり、`sample/test01/Export/`の目標LABと一致する。BPMを大きくすると各行の時間は短くなり、小さくすると長くなる。

## ラベルの決定

通常モードの各ノートに対するLABラベルは、[LABラベル判定規則](lab-labeling-rules.md)に従う。休符`R`は意図的に`sil`となり、かなも継続元の母音もない**非休符ノート**だけが`sil`＋ログ警告となる。

## 出力タイミングとログ

LABは「`.labも出力する`」をチェックした場合だけ、ExporterがUSTXとTXTを確定した後に同じトラック情報から作成する。話者マッピング、singer、renderer、フラグ設定はLABの内容に影響しない。BPMとノート位置・長さはLABの時刻に影響する。

ZIP内の変換ログには、LAB出力が有効かどうかを記録する。チェックした場合は、各トラックのLABパスとLAB行数も記録する。かなも継続元の母音もない非休符ノートを`sil`へ置換した場合は、その警告も記録する。

ノートの時間情報やBPMが不正でLABの時間範囲を算出できないなど、LABファイルの形式自体を成立させられない場合は、ZIP全体を不完全な状態でダウンロードせず、原因を画面内エラーとして表示する。

## 検証基準

- TXT、LAB、OpenUtau出力Wavの拡張子を除くファイル名が一致する。
- LABの行数は対応するUSTXトラックのノート数と一致する。
- 先頭行は0から開始し、隣接行に時間の隙間・重なりがない。
- BPM 200・240 ticksでは各行が`1500000`単位となる。
- 各ノートのラベルは[LABラベル判定規則](lab-labeling-rules.md)に従う。
- 休符`R`とは別に、かなも直前母音もない非休符ノートだけが`sil`としてLAB出力を継続し、ZIP内ログに対象モーラと位置の警告が記録される。
