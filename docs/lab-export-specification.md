# 口パク用LAB出力仕様

## 状態と目的

この文書は、セリフ付きZIPにPSDToolkit等の口パク用途向け`.lab`ファイルを追加するための実装仕様である。`.lab`はOpenUtauから書き出すWavと、既存のセリフTXTを対応付ける補助データであり、USTX単体ダウンロードには含めない。

出力直後のUSTXをOpenUtauで開き、ノートの位置・長さを変更せずにWavを書き出した場合、Wav、TXT、LABは同じファイル名で対応する。OpenUtau上でノート位置や長さを編集した場合はLABとの時間対応が変わるため、再変換して新しいZIPを出力する。

## ZIP内容の選択

LABを必要としない利用者も想定し、出力設定にZIP内容の選択項目を設ける。

| 選択肢 | ZIPの`Export/`に含めるもの | 想定用途 |
| --- | --- | --- |
| `TXTのみ`（初期値） | トラックごとのTXT | セリフ表示、YMMなどでの利用 |
| `TXT・LAB` | トラックごとのTXTとLAB | PSDToolkitなどでの口パク利用 |

この選択はExporterだけに影響する。変更してもImporterやGeneratorの再処理は行わず、次に「セリフ付きZIPをダウンロード」を押した時点で現在の選択を反映する。

## ZIP内の配置とファイル名

`TXT・LAB`を選択した場合、トラックごとにTXTとLABを同じ拡張子以外は完全に同一の名前で`Export/`へ出力する。

```text
project-name.zip
├─ project-name.ustx
├─ Export/
│  ├─ project-name_001.txt
│  ├─ project-name_001.lab
│  ├─ project-name_002.txt
│  └─ project-name_002.lab
└─ Log/
   └─ project-name_conversion.log
```

`001`などのトラック名は、利用者が選択したセリフファイル名形式に従う。したがって`プロジェクト名_トラック名.txt`、`プロジェクト名_トラック名.lab`、OpenUtauが出力する`プロジェクト名_トラック名.wav`は同じ名前の組になる。`TXTのみ`を選択した場合はLABを生成しないが、TXTとWavの対応は従来どおり維持する。

## LABのテキスト形式

LABはUTF-8のプレーンテキストとし、各行を以下の3列、半角スペース区切りで出力する。最終行の末尾には改行を付ける。

```text
開始時刻 終了時刻 ラベル
```

- 時刻は10進整数で記述する。開始時刻が0の場合は、目標ファイルに合わせて`00000`と表記してよい。
- ラベルは`a`、`i`、`u`、`e`、`o`、`N`、`sil`のいずれかとする。
- USTXの各ノートに対してLABを1行出力する。発声モーラだけでなく、先頭・句境界・促音・末尾を含むすべての休符Rも行として出力する。

## 時刻の算出

LABの時刻単位は、目標ファイルの実測値に合わせて**100ナノ秒単位**（1秒 = 10,000,000）とする。ナノ秒単位と呼ばれることがあるが、1秒 = 1,000,000,000の1ナノ秒単位ではない。

USTXの480 ticksを4分音符とし、各ノートの開始・終了tickをBPMから変換する。

```text
labTime(tick) = round(tick × 60 × 10,000,000 ÷ (480 × BPM))
```

各行の開始時刻にはノート開始tick、終了時刻には開始tick + 長さを与える。丸めは各絶対tick位置に対して行い、前行の終了時刻と次行の開始時刻が必ず一致するようにする。

HANAX-Uの現行ノート長はすべて240 ticksのため、1行の標準長は以下となる。

```text
300,000,000 ÷ BPM
```

BPM 200では1行 = `1500000`となり、`sample/test01/Export/`の目標LABと一致する。BPMを大きくすると各行の時間は短くなり、小さくすると長くなる。

## ラベルの決定

| 出力ノート | LABラベル |
| --- | --- |
| 休符`R` | `sil` |
| `ん`・`ン` | `N` |
| それ以外の発声モーラ | モーラ末尾の母音に対応する`a` / `i` / `u` / `e` / `o` |

母音は、通常のかな、拗音、小書き母音、ヴァ行を含め、発声モーラの末尾音から決定する。例として`きゃ`と`ヴぁ`は`a`、`しゅ`は`u`、`きょ`は`o`となる。長音記号がモーラとして現れる場合は、直前の発声モーラと同じ母音を引き継ぐ。

母音を決定できない文字が現れた場合は、黙って別のラベルへ置換せず、変換エラーとして扱う。これにより、PSDToolkitで口形がずれたまま気付きにくくなることを防ぐ。

## 出力タイミングとログ

LABは`TXT・LAB`を選択した場合だけ、ExporterがUSTXとTXTを確定した後に同じトラック情報から作成する。話者マッピング、singer、renderer、フラグ設定はLABの内容に影響しない。BPMとノート位置・長さはLABの時刻に影響する。

ZIP内の変換ログには、選択したZIP内容を記録する。`TXT・LAB`を選択した場合は、各トラックのLABパスとLAB行数も記録する。LAB出力に失敗した場合は、ZIP全体を不完全な状態でダウンロードせず、原因を画面内エラーとして表示する。

## 検証基準

- TXT、LAB、OpenUtau出力Wavの拡張子を除くファイル名が一致する。
- LABの行数は対応するUSTXトラックのノート数と一致する。
- 先頭行は0から開始し、隣接行に時間の隙間・重なりがない。
- BPM 200・240 ticksでは各行が`1500000`単位となる。
- `R`は`sil`、`ん`は`N`、発声モーラは対応する母音ラベルになる。
