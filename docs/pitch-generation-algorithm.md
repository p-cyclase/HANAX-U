# 音高生成アルゴリズム

## 目的

COEIROINKまたはVOICEVOXのプロジェクトからセリフのモーラ列とアクセント位置を取得し、藤崎モデルによって各モーラの基準周波数（F0）を再計算する。元プロジェクトに保存された実測ピッチは再現しない。

## 入力の正規化

- COEIROINKでは、保存されているアクセント句とモーラを利用する。
- VOICEVOXでは、アクセント句内のアクセント位置を、該当モーラだけが`accent: 1`となる内部形式へ変換する。
- VOICEVOXのモーラ表記はひらがなへ変換する。ただしヴァ行は`ヴァ`を`ヴぁ`のように変換する。
- VOICEVOXの実測pitch、子音長、母音長は音高計算に使わない。
- VOICEVOXの`pauseMora`は、COEIROINKにおける`、`モーラと同じ句境界として扱う。

## 時間軸とノート長

- 1モーラとすべてのRは240 ticks（8分音符相当）で出力する。
- BPMは藤崎モデル上の経過時間を決め、1モーラを`60 ÷ BPM ÷ 2`秒として計算する。
- 元プロジェクトのモーラごとの実時間長と、休止の実時間長は再現しない。

## 藤崎モデル

各モーラの中央時点において、基底周波数Fb、フレーズ成分、アクセント成分を合成してF0を求める。

- Fbは全体の基準音高であり、初期値は150 Hz。
- 各セリフの開始、`、`モーラ、`pauseMora`でフレーズ指令を置く。互換性のため`？`、`！`、`。`がモーラとして現れた場合も句境界として扱う。
- アクセント指令は、`accent: 1`のモーラの開始から終了まで有効とする。
- フレーズ減衰αとアクセント応答βは、各応答の時間変化を制御する。
- フレーズ成分の強さはUIで指定し、初期値は0.35。
- アクセント成分の強さはUIで指定し、初期値は0.45。

## 音高の量子化

藤崎モデルで得たF0をMIDI音高へ変換し、最も近い半音に丸める。発声音高は固定3段階ではなく、連続的なF0計算結果を半音単位で利用する。

## 休符R

すべてのRは240 ticksであり、以下の規則で半音単位の音高を持つ。

- セリフ先頭R、および句境界後の次モーラ先頭R：直後の発声モーラより3半音低い。
- 促音R：直前モーラがアクセントありなら直前より3半音上、そうでなければ3半音下。
- `、`、`！`、`。`の直前モーラ末尾R：直前モーラがアクセントありなら直前より3半音上、そうでなければ3半音下。
- `？`の直前モーラ末尾R：直前モーラより5半音上。
- `、`、`？`、`！`、`。`が文中にある場合、および`pauseMora`の場合は、末尾Rと次モーラ先頭Rの2つを出力する。
- これらが文末にある場合は、後続モーラがないため末尾Rだけを出力する。
- セリフの末尾がRでなければ、直前の発声モーラより3半音低い文末Rを1つ追加する。

## ポルタメント

各ノートは2点式のピッチカーブを持つ。開始点は直前ノートとの差、終点は当該ノートの音高とし、x座標にはUIのポルタメント長（ms）を使う。`snap_first`は常に`true`である。ビブラートの長さは0であり、実質的に無効である。
