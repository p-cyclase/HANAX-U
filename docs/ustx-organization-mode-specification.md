# USTX整頓モード仕様

> **対象：実装仕様・参考資料**
>
> 利用手順と制約の概要は[制作者向けワークフロー](for-creator.md)を参照する。この文書は、USTX整頓モードの入出力・検証・ログ仕様を記録する。

## 目的

OpenUtauで作成・編集したUSTXから、動画制作に使うトラック名、セリフTXT、口パク用LABを整えて再出力する。

通常のセリフ付きZIPでは、HANAX-Uが出力した直後のUSTXを基準にTXT・LABを生成する。その後にOpenUtauでノート位置・長さ・歌詞を編集すると、元のLABはWAVと時間対応しなくなる。USTX整頓モードは、このような編集後のUSTXを含め、OpenUtauで作成されたUSTXを入力として、WAV・TXT・LABの対応を整える独立した上級者向け機能である。HANAX-Uが出力したUSTXであることは前提にしない。

> **実装状況：試験機能**
>
> TXTの再出力とトラック名の再決定は利用できる。LABのラベルは[共通のLABラベル判定規則](lab-labeling-rules.md)に従う。音源固有の表記を言語的に解析する機能ではないため、LABを使う場合は動画制作環境での口パク結果を確認してから利用する。

## 位置付け

- 通常の`.cink`・`.vvproj`変換とは別の入力モードとする。
- WebUIの対応形式表示や通常導線には`.ustx`を加えない。
- README等の文書で、上級者向けの機能として存在と利用方法を案内する。
- 通常モードのImporter、Generator、話者マッピング、変換結果プレビューは利用しない。
- 通常のUSTX・セリフ付きZIP出力の仕様は変更しない。

## 入力

- 利用者がOpenUtauで編集した`.ustx`ファイルを、既存のドロップエリアへドロップまたはファイル選択で渡す。
- USTXとして解析できないファイルは、画面内に分かりやすいエラーを表示して処理を中止する。
- USTX内部の`name`、BPM、トラック、ボイスパート、ノート、アイテム名、各トラックの`singer`を読み取る。
- 整頓後のファイル名の基準は、入力した`.ustx`のファイル名から拡張子を除いた名前とする。USTX内部の`name`フィールドはファイル名の基準に使わず、変更もしない。

## 整頓時のUI状態

USTXを入力した場合は整頓モードへ切り替える。

- 変換設定（基本設定・詳細設定）は無効化する。藤崎モデルによる再計算は行わない。
- 話者マッピングは無効化する。入力USTXに保存されている各トラックの`singer`を使用する。
- 変換結果プレビューは無効化する。ノートの内容を再生成・表示しない。
- ファイル名形式の選択は有効とする。再出力するUSTX・TXT・必要に応じたLABの命名に使用する。
- 「`.labも出力する`」チェックボックスは有効とする。チェック時だけLABを出力する。
- 整頓モード専用のダウンロード操作により、整頓ZIPを出力する。

無効化した領域はグレーアウトし、「USTX整頓モードでは使用しません」と分かる表示にする。

## 整頓処理

### ノートの不変性

入力USTXに含まれるノートの位置、長さ、歌詞、音高、ピッチカーブ、各種パラメータは変更しない。

整頓モードが変更してよいのは、出力用に複製したUSTXのトラック名だけである。

### セリフTXT

各トラックのセリフTXT本文は、USTX内のボイスパート（OpenUtau上のアイテム）の`name`を使用する。ノート歌詞を連結して復元しない。

HANAX-Uが通常出力するUSTXは、各トラックにセリフを名前として持つボイスパートを1つ作成する。整頓モードはこの設計を利用できるが、HANAX-U以外で作成されたUSTXでも、存在するアイテム名を同じ規則で扱う。

1トラック内に複数のボイスパートがある場合は、位置順に各アイテム名を連結してTXT本文とする。アイテム名の間には文字を追加しない。ボイスパートが存在しない、またはすべてのアイテム名が空の場合は、空のTXTを出力し、ログに警告を記録する。

### LAB

LABは、編集後USTXの各トラックに含まれるすべてのノートを、トラック全体の時間軸上へ配置して出力する。アイテム単位で個別のLABを作るのではなく、1トラックにつき1つのLABを作る。

#### 時間軸への配置

各ノートの絶対tick位置は、所属するボイスパートの位置と、パート内ノート位置を足して求める。すべてのボイスパートのノートを集め、絶対tick位置の昇順に並べる。

ノートの前後に空白時間がある場合は、アイテム内・アイテム間を問わず、その空白区間を`sil`としてLABへ追加する。

- トラック開始時点（tick 0）から最初のノート開始までに空白があれば、`sil`を追加する。
- あるノートの終了から次ノートの開始までに空白があれば、`sil`を追加する。
- 最後のノート終了後は、USTX上で確定的なトラック終端を定められないため、追加の`sil`は出力しない。
- 休符`R`はノートそのものの区間を`sil`として出力する。空白区間に追加する`sil`とは区別せず、いずれも口パク上の無音を表す。

そのため、整頓モードで生成するLABの行数は、USTX内のノート数と一致しないことがある。これはノート間の空白を`sil`行として追加するための正常な結果である。

#### 時刻計算

時間範囲は、編集後のノート位置・長さと、編集後USTXのテンポ情報から算出する。

- テンポが1つだけの場合は、そのBPMでtickを時間へ換算する。
- テンポ変更がある場合は、各テンポ区間を順に積算してtickを時間へ換算する。単一のBPMへ丸めて計算してはならない。
- LABの書式と時刻単位は、通常モードのLAB出力と同じ100ナノ秒単位・3列のプレーンテキストとする。

#### ラベル

編集後のノート歌詞に対するLABラベルは、[LABラベル判定規則](lab-labeling-rules.md)に従う。整頓モードでは、ノート間の空白も`sil`として追加し、その後のノートは`sil`を保持した状態から判定する。

#### 既知の制約：特殊音素の口形は復元しない

suffix付き歌詞は末尾かな探索で、かなを含まない連続音・VC・独自エイリアスは直前ラベルの継続で扱う。そのため、従来のように特殊音素を一律`sil`へ置換することはない。

ただし、この方式は特殊音素が本来どの口形を表すかを特定するものではない。かなを含まない表記では、直前のラベルを保つことを優先する。トラック先頭、休符・空白の直後などでは`sil`を継続する。これらは通常の判定結果であり、ログ警告にはしない。口形の正確さが重要な場合は、実際の口パク結果を確認する。

整頓モードは試験機能であり、この制約を含めて改善を継続する。TXTの再出力とトラック名の再決定はLAB出力の有無にかかわらず実行できるため、LABが不要な用途では「`.labも出力する`」をオフにして利用できる。アイテム名が空の場合も空のTXTを出力し、トラック名の整理は継続する。音源固有の表記を壊さずLABラベルへ対応付ける方法は、今後検討する。

#### 同時発音

同一トラック内でノート区間が重なる場合、LABは同一時点へ複数の口形を記録できない。重なりはアイテム内・アイテム間を問わず検出する。

重なりを検出した場合は、整頓ZIPを出力せず処理を中止する。画面内には、重なっているノートを別トラックへ分けてから再実行するよう案内する。

### singerとトラック名の再決定

各トラックの`singer`は、入力USTXに保存された文字列をそのまま読み取る。話者マッピングは参照しない。

トラック名は、入力USTX内の元のトラック名にかかわらず、トラックの並び順に基づく3桁ゼロ埋め連番で振り直す。連番は1から開始する。

再決定後のトラック名は、整頓時点で選択されている「ファイル名形式」に従う。

| 選択肢 | 再決定後のトラック名 |
| --- | --- |
| 連番のみ | `001` |
| 連番_singer | `001_singer` |
| 連番_セリフ | `001_セリフ` |
| 連番_singer_セリフ | `001_singer_セリフ` |

`セリフ`には同トラックのアイテム名から得たTXT本文を使う。`singer`には入力USTXの`singer`を使う。各文字列の整形、文字数上限、singerが空の場合の代替文字列を含むトラック名の決定は、[ファイル命名規則](file-naming-rules.md)に従う。

再決定したトラック名は、複製したUSTX内の各トラックへ書き戻す。

## 出力ZIP

整頓モードの出力は、常に1つのZIPファイルとする。ZIPには次を含める。

```text
入力USTXのファイル名（拡張子なし）.zip
├─ 入力USTXのファイル名（拡張子なし）.ustx
├─ Export/
│  ├─ 入力USTXのファイル名（拡張子なし）_再決定後トラック名.txt
│  └─ 入力USTXのファイル名（拡張子なし）_再決定後トラック名.lab （LAB出力時のみ）
└─ Log/
   └─ 入力USTXのファイル名（拡張子なし）_ustx-organization.log
```

各トラックについてTXTを1つ出力する。「`.labも出力する`」が有効な場合は、同名のLABも1つ出力する。チェックボックスが無効な場合はLABを出力しない。

利用者はZIP内の再命名済みUSTXをOpenUtauで開き、WAVを書き出す。OpenUtauが出力するWAVは`入力USTXのファイル名（拡張子なし）_再決定後トラック名.wav`となるため、同じ`Export/`内のTXT・LABと拡張子以外のファイル名が一致する。

## ログ

ログは通常のZIPログと同じく、ZIP内の`Log/`へ1ファイル出力する。少なくとも次を記録する。

- 入力ファイル名と整頓日時
- 整頓モードであること
- 入力USTXのファイル名、USTX内部の`name`、BPM
- 各トラックの元のトラック名、再決定後のトラック名、singer、TXT本文、TXT・LABの出力パス
- LAB出力が有効かどうか、および有効な場合の各LABの行数
- 空のアイテム名など、出力を継続した警告
- 出力を中止したエラー

## エラーと継続方針

次の場合は整頓ZIPを出力せず、画面内エラーとして処理を中止する。

- USTXとして解析できない。
- BPM、トラック、ノートの必須構造を安全に読み取れない。
- BPMが有限の正の数ではない。
- ノート位置または長さが有限の数ではない、または長さが0以下である。
- ZIP生成に失敗した。

次の場合は出力を継続し、ログに警告を残す。

- ボイスパート名が空で、TXT本文が空になる。
- singerが空であり、既存の代替命名規則を使用した。
