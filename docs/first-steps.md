# はじめての一言を作る

このガイドでは、好きなUTAU音源に短いオリジナル台詞を言ってもらい、実際に聴くところまでを目標にします。

最初から動画、口パク、細かな調声まで完成させる必要はありません。まずは5〜10秒くらいの短い台詞を一つ完成させて、HANASU制作の流れをつかみましょう。

## 最初の目標

好きなUTAU音源に、5〜10秒程度のオリジナル台詞を話してもらい、聞いてみます。

たとえば、自己紹介や短いあいさつのような、少ない言葉から始めるのがおすすめです。曲のポエトリーパートや長い読み上げ動画を作りたい場合も、まずはこの短い台詞を完成させてから進むと、次の目標に取り組みやすくなります。

## 用意するもの

- COEIROINKまたはVOICEVOX
- OpenUtau
- 使いたいUTAU音源
- HANAX-U

使うUTAU音源の配布ページを確認し、利用条件やクレジット表記の必要性を確かめてください。無料で配布されている音源でも、利用できる範囲は音源ごとに異なります。

## 手順

1. COEIROINKまたはVOICEVOXで、短い台詞を入力します。
2. アクセントや話す速さを、分かる範囲で整えます。最初は細かく決めなくても大丈夫です。
3. プロジェクトを保存し、HANAX-Uへ`.cink`または`.vvproj`ファイルを読み込ませます。
4. 「.ustx をダウンロード」を選びます。設定を入力するところがたくさんありますが、まずはそのままで大丈夫です。
5. ダウンロードした`.ustx`をOpenUtauで開き、使いたいUTAU音源を設定します。
6. 音程、歌詞、タイミングなどを必要に応じて少し調整します。
7. OpenUtauからWavファイル（音声ファイル）を書き出し、完成した一言を聴きます。

HANAX-Uで作った音程は、COEIROINKやVOICEVOXで聴いた声のイントネーションと少し違って聞こえることがあります。これは、HANAX-Uが元の音程をそのまま使わず、別のしくみで音の高さを計算し直しているためです。

まずは、選んだUTAU音源が短い台詞を話してくれたら成功です。気になるところは、あとからOpenUtauで少しずつ直せます。

## 次にできること

短い一言を作れたら、台詞を少しずつ増やしたり、OpenUtauで調声してみたり、いろいろなことを試してみましょう。

COEIROINKやVOICEVOXで複数のキャラクターを使い、話者マッピング機能を使えば、複数のUTAU音源で掛け合いを作ることもできます。

動画ソフトで各種プラグインを設定して、「セリフ付きZIP」機能と組み合わせれば、動画にセリフを表示したり、口パクと連動させたりすることもできます。

## 困ったとき

- singerなどの項目が分からない場合は、空欄のままUSTXを出力し、OpenUtau側で音源を設定してかまいません。
- 音が思ったように聞こえない場合は、OpenUtauで音程、歌詞、タイミングを少しずつ調整してみてください。
- ファイルを読み込めない場合は、元のCOEIROINK／VOICEVOXプロジェクトが元のソフトで開けるかを確認してください。対応形式や入力時の注意は[README](../README.md)を参照してください。
