# はじめての一言を作る

このガイドでは、好きなUTAU音源に短いオリジナル台詞を言ってもらい、WAVファイルとして聴くところまでを目標にします。

最初から動画、口パク、細かな調声まで完成させる必要はありません。まずは5〜10秒くらいの短い台詞を一つ完成させて、HANASU制作の流れをつかみましょう。

## 用意するもの

- COEIROINKまたはVOICEVOX
- OpenUtau
- 使いたいUTAU音源
- HANAX-U

使うUTAU音源の配布ページを確認し、利用条件やクレジット表記の必要性を確かめてください。無料で配布されている音源でも、利用できる範囲は音源ごとに異なります。

## 最初の目標

好きなUTAU音源で、5〜10秒程度のオリジナル台詞をWAVとして書き出します。

たとえば、自己紹介や短いあいさつのような、少ない言葉から始めるのがおすすめです。曲のポエトリーパートや長い読み上げ動画を作りたい場合も、まずはこの短い台詞で一度流れを試すと、次の作業が進めやすくなります。

## 手順

1. COEIROINKまたはVOICEVOXで、短い台詞を入力します。
2. アクセントや話す速さを、分かる範囲で整えます。最初は細かく決めなくても大丈夫です。
3. プロジェクトを保存し、HANAX-Uへ`.cink`または`.vvproj`ファイルを読み込ませます。
4. 設定は初期値のままでかまいません。「.ustx をダウンロード」を選びます。
5. ダウンロードした`.ustx`をOpenUtauで開き、使いたいUTAU音源を設定します。
6. 音程、歌詞、タイミングなどを必要に応じて少し調整します。
7. OpenUtauからWAVファイルを書き出し、完成した一言を聴きます。

HANAX-Uが作る音高は出発点です。元のCOEIROINK／VOICEVOXプロジェクトの音程を再現するものではありません。OpenUtauで音源に合わせて直せるため、気になったところは後から変えられます。

## 次にできること

短い一言を作れたら、台詞を増やしたり、複数の音源を使った掛け合いを作ったりできます。

動画にセリフを表示したり、口パクと連動させたりしたくなった場合は、「セリフ付きZIP」を使うことでTXT・LABを出力できます。AviUtl、PSDToolkit、GCMZDrops、YMMなどの動画制作環境では別途プラグインや設定が必要になることがあるため、これは次の段階の機能として試すのがおすすめです。利用環境ごとの確認状況は[動画制作ツールとの連携状況](video-integration-status.md)を確認してください。

## 困ったとき

- まずは元のCOEIROINK／VOICEVOXプロジェクトを残しておいてください。変換をやり直せます。
- singerなどの項目が分からない場合は、空欄のままUSTXを出力し、OpenUtau側で音源を設定してかまいません。
- HANAX-Uの入力形式、設定、注意事項は[README](../README.md)を確認してください。
