# 制作者向けワークフロー

このガイドは、OpenUtauや動画制作環境をすでに使っており、HANASU制作の準備とファイル対応を整えたい制作者向けの案内です。

HANAX-Uは調声や動画編集を置き換えるものではありません。COEIROINK／VOICEVOXで台詞とアクセントの流れを作り、OpenUtauで音源らしさを仕上げ、必要に応じて動画制作へ渡すための下書きと受け渡しを担います。

HANAX-Uはv0.xの試験段階にあります。USTXの下書きを生成し、OpenUtauで編集する流れは中心機能として利用できます。一方、動画制作ツールとの自動連携は改善目標であり、環境ごとの動作確認は限定的です。

## 想定する使い方

- COEIROINKまたはVOICEVOXで、台詞とアクセントの流れをすばやく組む
- HANAX-UでUSTXを生成し、OpenUtauで音源、歌詞、音高、タイミングを調整する
- WAVと同名になるTXT・LABを用意し、対応する動画制作環境で利用する

HANAX-Uの変換結果は完成形ではなく、OpenUtauで確認・調整するための編集可能な下書きです。元プロジェクトの実測ピッチは利用せず、アクセント情報をもとに音高を再計算します。

## 基本ワークフロー

1. COEIROINKまたはVOICEVOXで、台詞・アクセント・話す流れを整えます。
2. HANAX-Uでプロジェクトを読み込みます。必要なら基本設定・詳細設定を調整し、「変更を反映」で音高を再生成します。
3. OpenUtauだけで仕上げる場合は`.ustx`を、動画連携にも進む場合は「セリフ付きZIP」を出力します。
4. OpenUtauで音源や調声を仕上げます。HANAX-Uの出力は下書きなので、必要な表現はここで十分に調整できます。
5. セリフ付きZIPを使う場合は、OpenUtauの「ファイル」→「音声をエクスポート」→「Wavファイルを出力」でWAVを書き出します。
6. `Export`フォルダ内で同名になるWAVとTXT・LABを、必要に応じて動画制作環境へ渡します。ツールごとの確認状況とキャラクターIDの扱いは、[動画制作ツールとの連携状況](video-integration-status.md)を参照してください。

TXT・LABとWAVのファイル名・時間対応を保つため、WAVを書き出す前にUSTXのプロジェクト名・トラック名・BPMを変更しないことをおすすめします。

ZIPの中身、編集後のLAB再出力、ファイル名形式については、[セリフ付きZIP・動画連携ガイド](zip-and-video-workflow.md)を参照してください。

## 話者マッピングと出力設定

話者ごとにsinger、phonemizer、rendererを指定できます。マッピングはUSTXを書き出す時点の設定を使います。singer名には、OpenUtauの`Singers`フォルダ内にある音源フォルダ名または相対パスを直接入力します。ファイル名形式にsingerを含める場合は、パスの末尾にあるフォルダ名だけを使います。

VOICEVOXのプロジェクトファイルには、キャラクター名やスタイル名そのものではなく、話者を識別するための内部IDが保存されています。HANAX-Uでは互換性を優先し、このIDをそのまま表示します。変な文字列に見えてもエラーではありません。プレビューのセリフを見て、どの話者IDがどのキャラクターに対応するかを確認してから、話者マッピングを設定してください。

フラグ設定は、プロジェクト全体の初期値です。生成後に音源やノートごとへ施す調整を置き換えるものではありません。

基底周波数もプロジェクト全体で指定します。話者ごとの音高・フラグ設定は現時点では出力できないため、必要な調整はOpenUtau上で行ってください。話者ごとの生成設定は将来の検討事項ですが、音高はGeneratorの入力となるため、追加には操作の流れを含めた設計の見直しが必要です。また、トラックごとのUTAUフラグ設定はOpenUtau安定版で利用できないため、HANAX-Uでは対応を見送っています。

## USTX整頓モード（試験機能）

OpenUtauでノート位置・長さ・歌詞を編集した後、WAVとTXT・LABの対応を作り直したい場合は、編集後の`.ustx`をHANAX-Uへ読み込めます。

USTX整頓モードでは、アイテム名からTXTを作り、ノート位置・長さ・歌詞を基にLABを再生成します。HANAX-Uが出力したUSTXに限らず、OpenUtauで作成・編集したUSTXに使用できます。アイテム名が空でも、空のTXTを出力してトラック名の整理は継続します。ノート、ピッチ、話者マッピング、通常の変換設定には変更を加えません。トラック名は、選択中のファイル名形式に従って付け直されます。

この機能は試験段階です。suffix・エイリアス・VC・CVVCなどの特殊音素ではLABの母音判定が期待どおりにならない場合があります。判定できない歌詞は`sil`として出力され、ZIP内のログへ記録されます。LABを使う場合は、ログと実際の口パク結果を確認してください。

詳細は[USTX整頓モード仕様](ustx-organization-mode-specification.md)を参照してください。

## 利用時の確認

音源、COEIROINK・VOICEVOXの音声ライブラリ、台詞に用いる作品には、それぞれ利用条件があります。HANAX-Uは利用可否を判断するものではないため、公開する作品では各配布ページ・規約を確認してください。

機能一覧、対応形式、制限、ログの扱いは[README](../README.md)を参照してください。
