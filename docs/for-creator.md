# 制作者向けワークフロー

このガイドは、OpenUtauや動画制作環境をすでに使っており、HANASU制作の準備とファイル対応を整えたい制作者向けの案内です。

HANAX-Uは調声や動画編集を置き換えるものではありません。COEIROINK／VOICEVOXで台詞とアクセントの流れを作り、OpenUtauで音源らしさを仕上げ、必要に応じて動画制作へ渡すための下書きと受け渡しを担います。

## 想定する使い方

- COEIROINKまたはVOICEVOXで、台詞とアクセントの流れをすばやく組む
- HANAX-UでUSTXを生成し、OpenUtauで音源、歌詞、音高、タイミングを調整する
- WAVと同名になるTXT・LABを用意し、PSDToolkitなどの動画制作環境で利用する

HANAX-Uの変換結果は完成形ではなく、OpenUtauで確認・調整するための編集可能な下書きです。元プロジェクトの実測ピッチは利用せず、アクセント情報をもとに音高を再計算します。

## 基本ワークフロー

1. COEIROINKまたはVOICEVOXで、台詞・アクセント・話す流れを整えます。
2. HANAX-Uでプロジェクトを読み込みます。必要なら基本設定・詳細設定を調整し、「変更を反映」で音高を再生成します。
3. OpenUtauだけで仕上げる場合は`.ustx`を、動画連携にも進む場合は「セリフ付きZIP」を出力します。
4. OpenUtauで音源や調声を仕上げます。HANAX-Uの出力は下書きなので、必要な表現はここで十分に調整できます。
5. セリフ付きZIPを使う場合は、OpenUtauの「ファイル」→「音声をエクスポート」→「Wavファイルを出力」でWAVを書き出します。
6. `Export`フォルダ内で同名になるWAVとTXT・LABを、必要に応じて動画制作環境へ渡します。

TXT・LABとWAVのファイル名・時間対応を保つため、WAVを書き出す前にUSTXのプロジェクト名・トラック名・BPMを変更しないことをおすすめします。

## 話者マッピングと出力設定

話者ごとにsinger、phonemizer、rendererを指定できます。マッピングはUSTXを書き出す時点の設定を使います。singer名には、OpenUtauの`Singers`フォルダ内にある音源フォルダ名を直接入力します。

フラグ設定は、プロジェクト全体の初期値です。生成後に音源やノートごとへ施す調整を置き換えるものではありません。

## 編集後USTXの再同期（試験機能）

OpenUtauでノート位置・長さ・歌詞を編集した後、WAVとTXT・LABの対応を作り直したい場合は、編集後の`.ustx`をHANAX-Uへ読み込めます。

再同期では、アイテム名からTXTを作り、編集後のノート位置・長さ・歌詞を基にLABを再生成します。ノート、ピッチ、話者マッピング、通常の変換設定には変更を加えません。トラック名は、選択中のファイル名形式に従って付け直されます。

この機能は試験段階です。suffix・エイリアス・VC・CVVCなどの特殊音素ではLABの母音判定が期待どおりにならない場合があります。判定できない歌詞は`sil`として出力され、ZIP内のログへ記録されます。LABを使う場合は、ログと実際の口パク結果を確認してください。

詳細は[USTX再同期モード仕様](ustx-resynchronization-mode-specification.md)を参照してください。

## 利用時の確認

音源、COEIROINK・VOICEVOXの音声ライブラリ、台詞に用いる作品には、それぞれ利用条件があります。HANAX-Uは利用可否を判断するものではないため、公開する作品では各配布ページ・規約を確認してください。

機能一覧、対応形式、制限、ログの扱いは[README](../README.md)を参照してください。
