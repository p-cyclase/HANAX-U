# 公開前テスト計画

> **対象：開発・検証向けの記録**
>
> この文書は、公開前の確認項目と実施条件を定める。

## 目的

公開前に、COEIROINK・VOICEVOXの両形式から期待どおりのUSTX・セリフ付きZIPを出力できること、およびOpenUtauで作成・編集したUSTXを整頓できることを確認する。ブラウザだけで確認できる項目と、OpenUtauおよびローカル音源が必要な項目を分けて実施する。

## 事前準備

- 権利上問題のないCOEIROINKプロジェクト（`.cink`）を用意する。
- 権利上問題のないVOICEVOXプロジェクト（`.vvproj`）を用意する。
- 話者マッピングの確認に使うUTAU音源を、OpenUtauのSingersフォルダへ配置する。
- Git管理する決定稿のテストデータは`test/`を使用する。ローカル専用の実用サンプルは`sample/`などGit管理対象外の場所に置く。

## ブラウザ内で確認する項目

以下は、COEIROINK・VOICEVOXの両方について確認する。

### 読み込みとプレビュー

- [ ] ファイルをドラッグ＆ドロップして読み込める。
- [ ] クリックによるファイル選択でも読み込める。
- [ ] セリフ行数・ノート数・音高範囲がプレビューに表示される。
- [ ] セリフ、休符R、音高がプレビューに表示される。
- [ ] VOICEVOXでは、話者IDとプレビューのセリフを対応付けられる。

### CINK／VVProjの正規化比較

`test/normal_success.cink`と`test/normal_success.vvproj`を、同一の変換設定でそれぞれ読み込んで確認する。

- [ ] ひらがな変換後のセリフ行、時間順のモーラ列、句境界が対応する。入力形式によるアクセント句の区切り方の違いは比較対象にしない。
- [ ] VOICEVOXのアクセント位置が、仕様どおりのモーラ単位アクセント情報へ正規化され、対応するCOEIROINK入力のアクセント有無と一致する。
- [ ] VOICEVOXの`pauseMora`と`isInterrogative: true`が、それぞれ`、`と`？`のモーラへ正規化される。
- [ ] プレビューに表示される歌詞、休符Rの位置、ノート位置・長さ、半音単位の音高が一致する。
- [ ] 促音`っ`はRとして出力され、Rの音高には促音自身を含む藤崎モデル計算結果が半音単位で反映される。
- [ ] 話者IDなど入力形式固有の出力メタデータは比較対象にしない。

### 変換設定

- [ ] 初期値のまま変換結果を作成できる。
- [ ] BPM、ポルタメント長、基底周波数を変更し、「変更を反映」でプレビューが更新される。
- [ ] 詳細設定を変更し、「変更を反映」でプレビューが更新される。
- [ ] 出力設定・話者マッピングを変更しても、音高計算が不要に再実行されない。

### フレーズ境界の処理

`test/normal_success.cink`と`test/normal_success.vvproj`を使い、次を確認する。

- [ ] 各`、`相当境界および`？`では、フレーズ成分が「フレーズ成分リセット閾値」以下なら、過去のフレーズ指令とアクセント成分を使わず、新しいフレーズ指令が置かれる。
- [ ] フレーズ成分リセット閾値より高く「フレーズ指令追加閾値」以下の境界では、状態を引き継いだまま新しいフレーズ指令が加わる。
- [ ] フレーズ指令追加閾値より高い境界では、状態を引き継ぎ、新しいフレーズ指令を置かない。
- [ ] しきい値と同じ値の場合は、リセット・指令追加を行う。
- [ ] フレーズ成分リセット閾値をフレーズ指令追加閾値より高く設定できない。
- [ ] しきい値を変えても、Rの数・位置・長さ・既存のR音高規則が変化しない。
- [ ] `normal_success.cink`の促音`っ`・`ッ`はRとして出力されてもフレーズ境界として扱われず、促音Rの前後で状態のリセットやフレーズ指令追加が発生しない。

### 保存設定と話者マッピング履歴

- [ ] 基本設定・詳細設定・フラグ設定・セリフ付きZIP設定を変更して出力をダウンロードした後、ページを開き直すと、出力に使った値が復元される。
- [ ] 新しい`.cink`または`.vvproj`を読み込んだ直後、話者マッピングは空欄から始まる。
- [ ] 話者マッピングを設定して出力をダウンロードした後、同じ`speaker_id`のsinger入力欄をクリックすると、出力に使ったsinger、phonemizer、rendererの組み合わせを候補から明示的に選択できる。
- [ ] 同じsinger名でphonemizerまたはrendererを変更して再度出力した場合、履歴には最新設定の候補だけが表示される。
- [ ] 別の話者・スタイルの履歴は表示されず、履歴を選んだ内容が現在の話者マッピングにだけ反映される。

### USTX・ZIP出力

- [ ] 「.ustx をダウンロード」でUSTXファイルを取得できる。
- [ ] 「セリフ付きZIPをダウンロード」でZIPファイルを取得できる。
- [ ] ZIPには、USTX、`Export/`内のセリフTXT、`Log/`内の変換ログが含まれる。
- [ ] ファイル名形式の3種類（連番のみ／連番_セリフ／連番_singer_セリフ）が出力名へ反映される。
- [ ] 通常変換・USTX整頓モードのどちらでも、[ファイル命名規則](file-naming-rules.md)どおりの文字数上限・相対パスのsinger名・使用できない文字の整形が適用される。
- [ ] フラグ設定（gender、breath、lowpass、normalize、modulation）がUSTXへ反映される。
- [ ] 話者マッピング（singer、phonemizer、renderer）が、ダウンロード時のUSTXへ反映される。
- [ ] 各ノートの`vibrato`は`length: 0`だけを持ち、周期・深さなどの追加パラメータを出力しない。

### 入力エラー

- [ ] `.cink`・`.vvproj`以外の形式で、分かりやすいエラーが表示される。
- [ ] 空ファイル、壊れたJSON、壊れたZIPで、画面内にエラーが表示される。
- [ ] サイズ上限を超えるファイルで、上限を示すエラーが表示される。
- [ ] 不正なファイルを選んだ後も、直前に成功した変換結果をダウンロードできる。

### USTX整頓モード

以下は`test/`の整頓モード用USTXを使用して確認する。通常の`.cink`・`.vvproj`変換とは別モードとして扱う。

- [ ] `resync_success.ustx`をドロップまたは選択すると、USTX整頓モードへ切り替わる。
- [ ] 整頓モードでは、変換設定、話者マッピング、変換結果プレビューが使用できず、出力設定カード内に整頓モードの説明が表示される。
- [ ] ファイル名形式と「`.labも出力する`」は有効のまま使用できる。
- [ ] `resync_success.ustx`から整頓ZIPを出力できる。
- [ ] 出力ZIPには、再命名済みUSTX、`Export/`内のTXT、LAB有効時のLAB、`Log/`内のログが含まれる。
- [ ] `resync_success.ustx`の入力USTXと出力USTXをYAMLとして構造比較し、各トラックの`track_name`以外の全フィールドが一致する。YAMLの整形・キー順・改行コードの差は比較対象にしない。
- [ ] トラック順に3桁ゼロ埋め連番を振り直し、選択中のファイル名形式が出力USTXのトラック名、TXT、LABへ反映される。
- [ ] singerあり・なしのトラックで、[ファイル命名規則](file-naming-rules.md)に従うsinger部分を確認できる。
- [ ] 入力USTXのsingerが空欄または空白だけの場合は、どちらも代替文字列`singer`を使って命名される。
- [ ] `resync_success.ustx`のコピーを使い、25文字以上のアイテム名と、8文字を超える最下層フォルダ名を持つsingerを設定して整頓ZIPを出力する。通常変換と同じく、セリフは24文字、singer名は8文字までに短縮され、USTXトラック名・TXT・LABのファイル名が一致する。
- [ ] 複数アイテムの名前が位置順に連結され、TXT本文になる。
- [ ] ノート間・アイテム間・トラック先頭の空白が、LABの`sil`行として出力される。
- [ ] テンポ変更前後のLAB時刻が、USTXのテンポ一覧に従って算出される。
- [ ] `resync_success.ustx`の通常モーラ後の`+`が、末尾かな探索で判定できない歌詞として直前ラベルを継続して出力される。
- [ ] `resync_warning.ustx`でZIP出力が継続し、suffix付き歌詞は末尾から見つかるかなに従って、かなを含まないエイリアス・VC・空欄歌詞は直前ラベルを継続して出力される。
- [ ] `resync_warning.ustx`のトラック先頭の`+`や休符直後の空欄歌詞は`sil`として出力され、母音判定に関するログ警告を出さない。
- [ ] `resync_warning.ustx`の入力USTXと出力USTXをYAMLとして構造比較し、各トラックの`track_name`以外の全フィールドが一致する。
- [ ] `resync_error1.ustx`と`resync_error2.ustx`で、ノート重なりを理由にZIP出力を中止する。
- [ ] `resync_error3.ustx`で、ノート位置に関係なくBPM 0を理由にZIP出力を中止する。

## OpenUtauで確認する項目

### USTXの読み込み

- [ ] USTX単体出力をOpenUtauで開ける。
- [ ] セリフ付きZIPに含まれるUSTXをOpenUtauで開ける。
- [ ] トラック数、歌詞、ノート長、休符Rがプレビューと大きく異ならない。
- [ ] ノートのピッチカーブが前ノートへ接続され、編集時に不自然なスナップが起きない。
- [ ] `vibrato: {length: 0}`だけを持つノートが、エラーなく読み込み・再生できる。
- [ ] 促音を含むセリフを使用するUTAU音源で再生またはレンダリングし、`a R`などの連続音を使う場合も促音前後が意図どおりに読めることを確認する。

### 話者マッピングと音声出力

- [ ] 話者マッピングを設定したトラックに、指定したsinger、phonemizer、rendererが反映される。
- [ ] 話者マッピングを空欄にしたトラックで、OpenUtau側から音源を設定できる。
- [ ] 使用する音源・rendererで再生またはレンダリングできる。

### セリフTXTとWavの対応

- [ ] ZIPを展開した状態でUSTXを開く。
- [ ] OpenUtauの「ファイル」→「音声をエクスポート」→「Wavファイルを出力」を実行する。
- [ ] `Export/`フォルダ内に、セリフTXTと同名のWavファイルが出力される。
- [ ] PSDToolkit、YMMなど、実際に利用するソフトウェアでTXTとWavを対応付けられる。

### 口パク用LABとWavの対応

- [ ] 「`.labも出力する`」をオフにした場合、従来どおりTXTだけが`Export/`に含まれ、LABは含まれない。
- [ ] 「`.labも出力する`」をオンにした場合、各TXTと同名のLABが`Export/`に含まれる。
- [ ] ファイル名形式または「`.labも出力する`」のオン・オフを変えても、音高計算やプレビューが再生成されない。
- [ ] LABとの時間対応を確認するWavは、ノート位置・長さを編集していないUSTXから出力する。
- [ ] TXT、LAB、OpenUtauから出力したWavの拡張子以外のファイル名が一致する。
- [ ] LABの行数が、対応するUSTXトラックのノート数と一致する。
- [ ] BPM 200・240 ticksのノートが、`1500000`（100ナノ秒単位）の長さで出力される。
- [ ] LABの隣接行に時間の隙間・重なりがない。
- [ ] `R`が`sil`、末尾から見つかる`ん`が`N`、母音を持つかなが対応する母音ラベルとして出力される。
- [ ] suffix付き歌詞は末尾からかなを探索して母音を判定し、かなを含まない`+`、連続音・VC、独自エイリアス、空欄歌詞は直前ラベルを継続する。
- [ ] トラック先頭または`R`の直後にかなを含まない歌詞がある場合は、`sil`を継続して出力する。母音判定に関するログ警告は記録しない。
- [ ] PSDToolkitで、LABと同名のWavを指定して口パクに利用できる。

### USTX整頓後のWav・TXT・LABの対応

- [ ] `resync_success.ustx`から出力した再命名済みUSTXをOpenUtauで開ける。
- [ ] OpenUtauからWavを書き出したとき、Wav、TXT、LABの拡張子以外のファイル名が一致する。
- [ ] 空白`sil`を含むLABが、編集済みノートのタイミングに沿ってPSDToolkitなどで利用できる。
