# 公開前テスト計画

## 目的

公開前に、COEIROINK・VOICEVOXの両形式から期待どおりのUSTX・セリフ付きZIPを出力できること、および編集済みUSTXを再同期できることを確認する。ブラウザだけで確認できる項目と、OpenUtauおよびローカル音源が必要な項目を分けて実施する。

## 事前準備

- 権利上問題のないCOEIROINKプロジェクト（`.cink`）を用意する。
- 権利上問題のないVOICEVOXプロジェクト（`.vvproj`）を用意する。
- 話者マッピングの確認に使うUTAU音源を、OpenUtauのSingersフォルダへ配置する。
- Git管理する決定稿のテストデータは`test/`を使用する。ローカル専用の実用サンプルは`sample/`などGit管理対象外の場所に置く。

## ブラウザ内で確認する項目

以下は、COEIROINK・VOICEVOXの両方について確認する。

### 読み込みとプレビュー

- [ ] ファイルをドラッグ＆ドロップして読み込める。
- [ ] クリックによるファイル選択でも読み込める。
- [ ] セリフ行数・ノート数・音高範囲がプレビューに表示される。
- [ ] セリフ、休符R、音高がプレビューに表示される。
- [ ] VOICEVOXでは、話者IDとプレビューのセリフを対応付けられる。

### 変換設定

- [ ] 初期値のまま変換結果を作成できる。
- [ ] BPM、ポルタメント長、基底周波数を変更し、「変更を反映」でプレビューが更新される。
- [ ] 詳細設定を変更し、「変更を反映」でプレビューが更新される。
- [ ] 出力設定・話者マッピングを変更しても、音高計算が不要に再実行されない。

### USTX・ZIP出力

- [ ] 「.ustx をダウンロード」でUSTXファイルを取得できる。
- [ ] 「セリフ付きZIPをダウンロード」でZIPファイルを取得できる。
- [ ] ZIPには、USTX、`Export/`内のセリフTXT、`Log/`内の変換ログが含まれる。
- [ ] ファイル名形式の3種類（連番のみ／連番_セリフ／連番_singer_セリフ）が出力名へ反映される。
- [ ] フラグ設定（gender、breath、lowpass、normalize、modulation）がUSTXへ反映される。
- [ ] 話者マッピング（singer、phonemizer、renderer）が、ダウンロード時のUSTXへ反映される。

### 入力エラー

- [ ] `.cink`・`.vvproj`以外の形式で、分かりやすいエラーが表示される。
- [ ] 空ファイル、壊れたJSON、壊れたZIPで、画面内にエラーが表示される。
- [ ] サイズ上限を超えるファイルで、上限を示すエラーが表示される。
- [ ] 不正なファイルを選んだ後も、直前に成功した変換結果をダウンロードできる。

### USTX再同期モード

以下は`test/`の再同期モード用USTXを使用して確認する。通常の`.cink`・`.vvproj`変換とは別モードとして扱う。

- [ ] `resync_success.ustx`をドロップまたは選択すると、USTX再同期モードへ切り替わる。
- [ ] 再同期モードでは、変換設定、話者マッピング、変換結果プレビューが無効化され、「このモードでは使用しません」と分かる表示になる。
- [ ] ファイル名形式と「`.labも出力する`」は有効のまま使用できる。
- [ ] `resync_success.ustx`から再同期ZIPを出力できる。
- [ ] 出力ZIPには、再命名済みUSTX、`Export/`内のTXT、LAB有効時のLAB、`Log/`内のログが含まれる。
- [ ] `resync_success.ustx`の入力USTXと出力USTXをYAMLとして構造比較し、各トラックの`track_name`以外の全フィールドが一致する。YAMLの整形・キー順・改行コードの差は比較対象にしない。
- [ ] トラック順に3桁ゼロ埋め連番を振り直し、選択中のファイル名形式が出力USTXのトラック名、TXT、LABへ反映される。
- [ ] singerあり・なしのトラックで、既存命名規則に従うsinger部分を確認できる。
- [ ] 複数アイテムの名前が位置順に連結され、TXT本文になる。
- [ ] ノート間・アイテム間・トラック先頭の空白が、LABの`sil`行として出力される。
- [ ] テンポ変更前後のLAB時刻が、USTXのテンポ一覧に従って算出される。
- [ ] `resync_success.ustx`の通常モーラ後の`+`が、直前母音を引き継いで出力される。
- [ ] `resync_warning.ustx`でZIP出力が継続し、suffix、エイリアス、VC等の特殊音素、空欄歌詞、引き継ぐ母音がない`+`が`sil`とログ警告になる。
- [ ] `resync_warning.ustx`の入力USTXと出力USTXをYAMLとして構造比較し、警告の有無にかかわらず、各トラックの`track_name`以外の全フィールドが一致する。
- [ ] `resync_error1.ustx`と`resync_error2.ustx`で、ノート重なりを理由にZIP出力を中止する。
- [ ] `resync_error3.ustx`で、ノート位置に関係なくBPM 0を理由にZIP出力を中止する。

## OpenUtauで確認する項目

### USTXの読み込み

- [ ] USTX単体出力をOpenUtauで開ける。
- [ ] セリフ付きZIPに含まれるUSTXをOpenUtauで開ける。
- [ ] トラック数、歌詞、ノート長、休符Rがプレビューと大きく異ならない。
- [ ] ノートのピッチカーブが前ノートへ接続され、編集時に不自然なスナップが起きない。

### 話者マッピングと音声出力

- [ ] 話者マッピングを設定したトラックに、指定したsinger、phonemizer、rendererが反映される。
- [ ] 話者マッピングを空欄にしたトラックで、OpenUtau側から音源を設定できる。
- [ ] 使用する音源・rendererで再生またはレンダリングできる。

### セリフTXTとWavの対応

- [ ] ZIPを展開した状態でUSTXを開く。
- [ ] OpenUtauの「ファイル」→「音声をエクスポート」→「Wavファイルを出力」を実行する。
- [ ] `Export/`フォルダ内に、セリフTXTと同名のWavファイルが出力される。
- [ ] PSDToolkit、YMMなど、実際に利用するソフトウェアでTXTとWavを対応付けられる。

### 口パク用LABとWavの対応

- [ ] 「`.labも出力する`」をオフにした場合、従来どおりTXTだけが`Export/`に含まれ、LABは含まれない。
- [ ] 「`.labも出力する`」をオンにした場合、各TXTと同名のLABが`Export/`に含まれる。
- [ ] ファイル名形式または「`.labも出力する`」のオン・オフを変えても、音高計算やプレビューが再生成されない。
- [ ] LABとの時間対応を確認するWavは、ノート位置・長さを編集していないUSTXから出力する。
- [ ] TXT、LAB、OpenUtauから出力したWavの拡張子以外のファイル名が一致する。
- [ ] LABの行数が、対応するUSTXトラックのノート数と一致する。
- [ ] BPM 200・240 ticksのノートが、`1500000`（100ナノ秒単位）の長さで出力される。
- [ ] LABの隣接行に時間の隙間・重なりがない。
- [ ] `R`が`sil`、`ん`が`N`、発声モーラが対応する母音ラベルとして出力される。
- [ ] 発声モーラの直後にある`+`、および連続する`+`が、元となる発声モーラと同じ母音ラベルとして出力される。
- [ ] 先頭または休符の直後にある`+`が`sil`となり、ZIP内ログに警告が記録される。
- [ ] 判定不能なモーラがあってもZIP出力は継続し、該当LABラベルが`sil`、ZIP内ログに対象モーラと位置の警告が記録される。
- [ ] PSDToolkitで、LABと同名のWavを指定して口パクに利用できる。

### USTX再同期後のWav・TXT・LABの対応

- [ ] `resync_success.ustx`から出力した再命名済みUSTXをOpenUtauで開ける。
- [ ] OpenUtauからWavを書き出したとき、Wav、TXT、LABの拡張子以外のファイル名が一致する。
- [ ] 空白`sil`を含むLABが、編集済みノートのタイミングに沿ってPSDToolkitなどで利用できる。

## 記録

確認した日付、ブラウザ、OpenUtauのバージョン、使用した音源・renderer、結果を記録する。不具合が見つかった場合は、入力形式、再現手順、画面内エラーまたはZIP内ログを添えてIssueとして管理する。
